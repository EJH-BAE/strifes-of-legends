# Strifes of Legends updates

unofficial game (similar to LoL)

`update.json` is the live feed. The installed game and Strife Manager read it on launch.

`SoLSetup.exe` installs both Strife Manager and Strifes of Legends into `C:\Strifes of Legends`. When `version` is higher than the installed build, the client downloads `installer` and runs that setup.
